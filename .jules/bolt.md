## 2026-07-31 - [Decoupled State Filter Debounce and Inline Render Component Anti-patterns]
**Learning:** Defining helper render components inside parent components and rendering them as JSX tags (e.g., `<FilterContent />`) causes React to treat them as new component types on every render, resulting in complete DOM unmounting and remounting. This destroys input focus, resets local states, and causes severe rendering lag. Changing them to direct function calls (e.g., `{renderFilterContent()}`) fixes this immediately. Coupling input text to URL query sync on every keystroke also degrades Interaction to Next Paint (INP) because `router.replace` updates are synchronously scheduled. Decoupling search values using debounced local state ensures completely smooth typing.
**Action:** Decouple list filtering text inputs from parent list state, use a debounced update (e.g., 200ms) before filtering or pushing to URLs, and always invoke inline render helpers as plain functions rather than JSX tags.
