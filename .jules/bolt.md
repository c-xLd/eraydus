## 2026-02-15 - Nested Helper Components Anti-Pattern in React Render Loop
**Learning:** Defining helper components inline inside a parent component (e.g., `const FilterContent = () => ...` inside `ProductFilters`) and rendering them as JSX tags (`<FilterContent />`) is a severe performance anti-pattern. React treats this as a newly declared component type on *every single render* of the parent component, causing it to completely unmount and remount the entire DOM subtree. This triggers excessive layout recalculations, resets native scroll/input states, forces DOM thrashing, and heavily degrades Interaction to Next Paint (INP) / layout performance.
**Action:** Either lift the nested component outside of the parent component's definition or return the JSX directly from the parent render tree without wrapping it in a nested functional component reference.
